# Health-Inspection-Analysis
A Python-based data analytics project exploring food inspection records through data cleaning, exploratory data analysis, visualization, and key insights into inspection scores, risk categories, violations, and business characteristics.

📌 Project Overview

This project focuses on the analysis of food inspection data using Python. The main objective is to clean, explore, visualize, and analyse food inspection records to identify important patterns and insights related to food safety, inspection scores, risk categories, violations, and business characteristics.
The project follows a complete data analytics workflow, starting from raw data preparation and cleaning and progressing through exploratory data analysis (EDA), visualization, and insight generation.

🎯 Objectives
* Clean and preprocess the raw food inspection dataset.
* Identify and handle missing values and inconsistent data.
* Detect and analyse outliers in numerical variables.
* Explore the distribution of important variables.
* Analyse relationships between inspection scores, risk categories, violations, and other variables.
* Create meaningful visualizations to communicate findings.
* Generate useful insights from the data.
  
🛠️ Tools and Technologies
* Python
* Pandas – Data cleaning and manipulation
* NumPy – Numerical analysis
* Matplotlib – Data visualization
* Seaborn – Statistical visualization
* Jupyter Notebook – Analysis and documentation
